** MSYS2
This is for any Windows user. When you're developing software, you'll often need a way to manage the dependencies and the build tools needed to use these software. Imagine just installing EXE files from the web and hope for the best without being able to keep clear track of versions. You can of course use Microsoft Visual Studio. However, if you have prior experience with Replit, it's easier to get started with an environment that is UNIX-like. But perhaps the most convincing reason to try out MSYS2 is that you're looking for a lightweight option to just create a C++ program rather than installing the massive Visual Studio tooling library.

Here's what you're going to use:
- Code Editor: Visual Studio Code \to Install Directly From Website
- MSYS2 - https://www.msys2.org/ \to Install From Getting Started Play
- CMake, GCC, Ninja, GoogleTest and any other tools you would need (e.g. SDL3) \to MYSYS2 UCRT64 packages through pacman.

You can follow the guide for setting up Visual Studio Code here https://www.msys2.org/docs/ides-editors/.

For the actual environment:
https://code.visualstudio.com/docs/languages/cpp#_example-install-mingw-x64-on-windows
