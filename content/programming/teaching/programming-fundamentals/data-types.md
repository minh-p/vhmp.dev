After learning [values]({{< relref "values" >}}) are, it's about time for you to choose a programming language as we begin to write code.

Many students might choose Python as their first programming language because of its easy to remember syntax while sticking to conventional programming rules. If you are ambitious, you might choose Java because it's the most widely used programming language for big corporations. Some young students choose Lua because they would like to work with Roblox. Or as trial by fire, a student could go directly to C and C++ (which I wouldn't recommend).

My personal recommendations: Python for a general student, and Lua for a student who wants to directly make Roblox games.
